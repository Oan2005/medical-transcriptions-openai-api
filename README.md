## Organizing Medical Transcriptions with the OpenAI API

## Overview

This project explores the use of the OpenAI API to process and organize medical transcription text.

Completed as part of a DataCamp guided project, it demonstrates practical experience working with an LLM API through Python.

## Objectives

- Process medical transcription text using an LLM API.
- Explore how an API can support text organization and processing.
- Practice integrating an external AI service into a Python workflow.

## Technologies

- Python
- Jupyter Notebook
- OpenAI API

## Project Structure

- `medical_transcriptions.ipynb` — Notebook containing the project workflow and analysis.

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Configure your API credentials using environment variables.
4. Open the notebook and execute the cells in order.

Never place API keys directly in the notebook or commit them to GitHub.
